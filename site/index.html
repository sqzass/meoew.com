a custom discord desktop app. vesktop's body, doiksub's brain, and a cute aesthetic.

about

meoew, a potentially broken but fun discord client with the doiksub mod preinstalled. forked from vesktop.

plugins

the plugins are listed on the readme, but here's the quick version. change your account locally - yk those larping/fake vids of "three letter usernames" or "i have the discord account" videos? yeah, we got that plugin. the most updated version too. message loggers, auto-complete quests, avatar grabber, 'whois' as well. basically, vencord + minimal equicord, then questionable and definitely abusive plugins sprinkled in.

Description

meoew is what happens when you take vesktop, rip out useless plugins, wire it straight into doiksub broken builds, and then pray it works.

  • discord gets nothing about your system it doesn't need
  • linux screenshare with audio, wayland included
  • curated plugin set

Install

$ git clone https://github.com/sqzass/meoew.com.git
$ cd meoew.com
$ pnpm i
$ pnpm package      // builds for YOUR specific os, output in dist

don't feel like building? grab artifacts from the latest actions run. windows, macos and linux are built on every push.

Bugs

surely some. report them at the issue tracker, or in the discord, whichever you're already open in.
